# VFS Shell Emulator

## 1. Общее описание

VFS Shell Emulator — это графическое приложение, которое имитирует работу командной оболочки Unix/Linux операционной системы. Приложение взаимодействует с виртуальной файловой системой (VFS) через графический интерфейс пользователя (GUI).

Проект разрабатывается поэтапно:
- **Этап 1 (текущий)**: REPL — базовый прототип с GUI и парсером команд
- **Этап 2**: Конфигурация — параметры командной строки и YAML-конфиг
- **Этап 3**: VFS — подключение виртуальной файловой системы
- **Этап 4**: Основные команды — полная реализация ls, cd и других команд
- **Этап 5**: Дополнительные команды — команды изменения состояния VFS

### Технологии

- Язык: Java 11+
- GUI: Swing (встроенная библиотека Java)

## 2. Описание всех функций и настроек

### Функции Этапа 1

#### Графический интерфейс (GUI)

- **Окно приложения**
    - Заголовок: "VFS Shell Emulator"
    - Размер: 800×600 пикселей
    - Располагается в центре экрана

- **Верхняя часть** — Область вывода (JTextArea)
    - Выводит результаты команд
    - Не редактируется пользователем
    - Шрифт: Courier New, размер 12pt
    - Поддерживает прокрутку

- **Нижняя часть** — Поле ввода (JTextField)
    - Место для ввода команд
    - Нажатие Enter выполняет команду
    - Тот же шрифт для единообразия

#### Парсер команд

- Разбивает введённый текст по пробелам
- Первый элемент — название команды
- Остальные элементы — аргументы команды
- Пример: `ls -la /home` → команда: `ls`, аргументы: `-la`, `/home`

#### Команды

**`ls` — список файлов**
- Без аргументов: выводит список файлов в текущей папке
- С аргументами: выводит команду и аргументы
- Заглушка: выводит `file1.txt  file2.txt  folder1`

**`cd <директория>` — смена директории**
- Требует обязательный аргумент (путь к папке)
- Без аргумента: выводит ошибку `ERROR: cd requires a directory argument`
- Заглушка: выводит `Changed directory to: <путь>`

**`exit` — выход из программы**
- Завершает приложение
- Выводит сообщение `Exiting VFS Shell Emulator...`

#### Обработка ошибок

- **Неизвестная команда**: `ERROR: Unknown command: <команда>`
- **Неверные аргументы для cd**: `ERROR: cd requires a directory argument`
- **Ошибки выполнения**: выводятся в область вывода
